# Lab 2: Pointers in C++ — Dynamic Memory, Pointer Arithmetic & Memory Management

## Introduction

This lab focuses on revising and strengthening the use of pointers in C++. Students will work with pointer arithmetic, arrays, pointer-to-pointer variables, and dynamically allocated memory.

The lab introduces concepts that are important for understanding how dynamic data structures are implemented in C++. Students will also practice allocating, accessing, modifying, and releasing memory correctly.

## Objectives

Students will:

- Practice using pointers and pointer arithmetic in C++.
- Understand how pointers interact with arrays.
- Practice using pointer-to-pointer variables.
- Work with dynamically allocated memory using `new` and `delete[]`.
- Understand memory management and avoid memory leaks.
- Identify common pointer errors such as out-of-bounds access and dangling pointers.
- Develop programs that use dynamic memory to solve practical problems.
- Strengthen problem-solving and debugging skills.

## Tools / Software Requirements

- Visual Studio C++ or any standard C++ IDE such as:
  - Code::Blocks
  - CLion
  - Visual Studio Code with a g++ compiler

## Description

Students will begin by revising pointer fundamentals and pointer arithmetic. They will then apply pointers to arrays, functions, and dynamically allocated memory.

Each task emphasizes:

- Correct pointer usage
- Pointer arithmetic
- Dynamic memory allocation
- Memory deallocation
- Problem-solving
- Code readability and comments
- Understanding memory-related errors

## Tasks

The lab contains the following tasks:

- **Task 1** — Determine the memory size occupied by different C++ data types.
- **Task 2** — Explore pointer arithmetic and memory addresses.
- **Task 3** — Traverse an array using pointers.
- **Task 4** — Trace and determine the output of pointer-based C++ programs.
- **Task 5** — Use pointers and pointer-to-pointer variables to swap values.
- **Task 6** — Dynamically allocate a 2D marks array using `int**` and manage its memory.
- **Task 7** — Dynamically expand an array when a new student/mark is added.
- **Task 8** — Identify and correct common dynamic-memory and pointer errors.

## Pointer & Memory Management

The lab uses dynamic memory allocation to demonstrate how memory can be created and released during program execution.

Students will practice:

- Allocating memory using `new`
- Allocating arrays using `new[]`
- Accessing dynamically allocated memory through pointers
- Releasing memory using `delete[]`
- Setting pointers to `nullptr` after releasing their memory
- Understanding dangling pointers
- Identifying memory leaks and out-of-bounds accesses

## Testing

Programs should be tested using the cases provided in the lab instructions. Students should verify that their programs produce the expected results and correctly handle the required input cases.
